# Experimental Levels 61–66

These are archived, inactive design samples. They are deliberately stored outside `Resources`, and the playable fixed-level sequence ends at Level 60. `EnableExperimentalLevels61To66` in `CarPrototype3D` is disabled.

| Level | Sample | Main thinking skill | Runtime status |
|---|---|---|---|
| 61 | The Long Way Out | Trace blocking dependencies before tapping | Inactive archive |
| 62 | Four Is Not Five | Avoid an attractive incomplete color match | Inactive archive |
| 63 | Valet Exchange | Plan a limited sequence of side-parking entries | Inactive archive |
| 64 | Key Color | Complete green to unlock a visible red car | Inactive archive |
| 65 | Traffic Schedule | Complete red, green, blue, then yellow | Inactive archive |
| 66 | Rush-Hour Finale | Combine locks, order, parking, and limousines | Inactive archive |

The JSON definitions remain only as archived design notes. The runtime does not append them, so Boards 1–60 and the database asset remain the complete playable progression.

Use **Color Sort → Validate Experimental Levels 61–66** in Unity to check the archive. Validation confirms that every sample references a real 5×5 board, the runtime sequence remains capped at 60, and the archived rules cannot enter gameplay.
